Turn any research paper into a runnable Jupyter notebook.

Pick a PDF. The app extracts text and math, removes citations and references to save tokens, sends it to your chosen AI (OpenAI, Anthropic, Gemini, or local Ollama), and writes a .ipynb that reproduces the paper's experiments — nothing more, nothing less.

Download for your OS View on GitHub

Math-aware extraction

Local Python extractor captures equations, tables, and layout. No cloud upload of your PDF.

Token-optimized

Strips citations, clips bibliography, normalizes whitespace. Shows raw vs cleaned char/token counts.

Exact reproduction

System prompt enforces the paper's architecture, data, loss, optimizer, hyperparameters, and metrics — no extras.

Your keys, your machine

API keys are used only in-memory. Pick OpenAI, Anthropic, Gemini, or run fully offline with Ollama.

Clean file management

PDFs go to papers/, notebooks to notebooks/, same filename stem, versioned on collision.

Cross-platform

Windows, macOS, Linux. Built with Tauri v2 + Rust. Small binary, native performance.

Requires Python 3 with pymupdf (and optionally pymupdf4llm, pypdf, docling) installed. An API key for your chosen provider is required unless using Ollama.

How it works

  1. 1. Extract. Local Python engine reads the PDF and preserves equations, tables, layout.
  2. 2. Clean. Rust strips citation brackets, author-year cites, and cuts everything from "References" onward. Shows token savings.
  3. 3. Generate. Your paper text is sent to the model you picked, in chunks if needed, with a strict prompt for exact reproduction.
  4. 4. Compile. Model output is parsed into nbformat 4.5 cells (Markdown + Code) and written as <paper>.ipynb.
